KitX

A kit management addon for Minecraft Bedrock. Save kits, equip them in one command, and control who can use them.

Get KitX on CurseForge Open the Preset Builder

What is KitX?

KitX stores kits in your world, so they survive addon updates. Each kit can be Open, Locked or Limited to certain players, can have a cooldown, and can be hidden from the list. There's an in-game menu, per-player layouts, and backups that survive version changes.

This site has companion tools for it. You don't need them to use KitX, but they make big kit sets easier to prepare.

Kit BuilderLay out a kit slot by slot and export it as a .mcstructure file. Preset BuilderBundle kit files into a preset addon that you add next to KitX.

How the tools fit together

  • Make a kit in the Kit Builder and export it as a .mcstructure file.
  • Add one or more of those files to the Preset Builder, name your pack, and download the .mcaddon.
  • Import the file into Minecraft, enable it in the world next to the main KitX addon, and use the Presets screen in KitX's Backup menu.

Preset Builder

Add your kit structure files, name your pack, and download a preset addon to use alongside KitX. Everything runs in your browser; nothing is uploaded anywhere.

1 · Pack details

No icon chosen. The pack is built without one until the KitX default icon is added to this site.

2 · Kit structures

Tap to choose .mcstructure files, or drop them here

Each file becomes one kit preset. The kit name comes from the file name and you can rename it. Names are lowercased and limited to a-z 0-9 _.

3 · Build

Output is a .mcaddon with a fresh pack UUID and module UUID on every build. Import it on your device, enable it in the world next to the main KitX addon, then use the Presets screen in KitX's Backup menu.
