KitX Web Builder

A collection of browser-based tools for KitX, the Minecraft Bedrock kit management addon.

Tools

- Kit Builder – Create kits slot by slot and export them as ".mcstructure" files.
- Preset Builder – Combine kit structures into downloadable ".mcaddon" preset packs.
- Preview Builder – Extend KitX's item preview compatibility to items and blocks from other addons.

Features

- Runs directly in your browser.
- No uploads or external storage required.
- Generates downloadable Minecraft Bedrock files.
- Designed to work alongside KitX.
